# BRAC Bank PLC — Financial Performance Analysis (2021–2025)

A five-year financial analysis of BRAC Bank PLC, examining its financial performance, profitability, operational efficiency, asset quality, and capital adequacy.

## Overview

This project evaluates the financial performance and position of BRAC Bank PLC over the 2021–2025 period using publicly available annual reports and audited financial statements.

The objective is to identify historical financial trends, assess profitability, evaluate operational efficiency, and examine the bank's overall financial health.
